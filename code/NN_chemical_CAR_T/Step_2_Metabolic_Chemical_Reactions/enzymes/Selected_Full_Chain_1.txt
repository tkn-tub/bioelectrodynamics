POLARITY AND TIMESCALES
  Each stage is INVERTING. The fast arm raises the gated degradation of
  m_d_k before the slow arm raises its production, so a rising stage input
  drives m_d_k DOWN from its baseline. Stage gains: -1, -1 -> net +1.
  Consequence: m_d1 encodes -d(m_in)/dt and m_d2 encodes +d2(m_in)/dt2.
  Both ride on a POSITIVE baseline and the pulse is an excursion about it:
      m_d_k* = v_Sd / ( k_lk + V_I * f(m_Fd_k*) )   must be > 0
  so r_lk and the saturated r_I must not between them exceed v_Sd at rest.
  Both arms have TWO steps, so the fast/slow split is kinetic, not
  topological. Load enzymes so that, per stage:
      tau_F = 1/k_Ff + 1/k_Fd  <  tau_S = 1/k_Sf + 1/k_Sd
      r_I saturated in m_d_k  (m_d_k* >> K_M)  -> subtracts a FLUX
      r_lk first order in m_d_k (m_d_k* << K_M) -> sets the baseline
      m_Fd_k below saturation at the activator site -> graded gate
